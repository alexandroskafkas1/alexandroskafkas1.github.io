Quiz 1: Vectors, Dot Product, Cross Product, and Planes

Date: 08/25/2026

Problem 1

[8 points]

Let \(\mathbf{u} = \langle 3, -2, 1 \rangle\) and \(\mathbf{v} = \langle 1, 2, 4 \rangle\).

  1. Compute the vector \(2\mathbf{u} - 3\mathbf{v}\) in component form.
  2. Compute the dot product \(\mathbf{u} \cdot \mathbf{v}\) and determine if \(\mathbf{u}\) and \(\mathbf{v}\) are orthogonal.
View Solution
  1. $$\begin{aligned} 2\mathbf{u} - 3\mathbf{v} &= 2\langle 3, -2, 1 \rangle - 3\langle 1, 2, 4 \rangle \\ &= \langle 6, -4, 2 \rangle - \langle 3, 6, 12 \rangle = \langle 3, -10, -10 \rangle \end{aligned}$$
  2. $$\mathbf{u} \cdot \mathbf{v} = (3)(1) + (-2)(2) + (1)(4) = 3 - 4 + 4 = 3$$ Since \(\mathbf{u} \cdot \mathbf{v} \neq 0\), the vectors are not orthogonal.

Problem 2

[12 points]

Consider the vectors \(\mathbf{a} = \langle 1, 2, 0 \rangle\) and \(\mathbf{b} = \langle 0, 3, 1 \rangle\).

  1. Find the cross product \(\mathbf{a} \times \mathbf{b}\).
  2. Find the scalar equation of the plane passing through the point \(P(2, -1, 4)\) with normal vector \(\vec{n} = \mathbf{a} \times \mathbf{b}\).
View Solution
  1. $$\mathbf{a} \times \mathbf{b} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ 1 & 2 & 0 \\ 0 & 3 & 1 \end{vmatrix} = \mathbf{i}(2 - 0) - \mathbf{j}(1 - 0) + \mathbf{k}(3 - 0) = \langle 2, -1, 3 \rangle$$
  2. Using point \(P(2, -1, 4)\) and normal \(\vec{n} = \langle 2, -1, 3 \rangle\): $$\begin{aligned} 2(x - 2) - 1(y - (-1)) + 3(z - 4) &= 0 \\ 2x - 4 - y - 1 + 3z - 12 &= 0 \\ 2x - y + 3z &= 17 \end{aligned}$$

Quiz 2: Vector Functions, Domain, Parametrization, and Tangent Lines

Date: 09/01/2026

Problem 1

[8 points]

Answer the following questions:

  1. Find the domain of the vector-valued function \(\mathbf{r}(t) = \langle \sqrt{t+2}, \; \ln(6-t), \; 5t \rangle\). Express your answer in interval notation.
  2. Find a vector parametrization \(\mathbf{r}(t)\) for the curve of intersection of the circular cylinder \(x^2 + y^2 = 4\) and the plane \(z = 3x - y\).
View Solution
  1. Find the domain of each component:
    • \(\sqrt{t+2} \implies t+2 \ge 0 \implies t \ge -2\)
    • \(\ln(6-t) \implies 6-t > 0 \implies t < 6\)
    • \(5t\) is defined for all \(t \in \mathbb{R}\)
    Taking the intersection yields: $$\text{Domain} = [-2, 6)$$
  2. Parametrize the cylinder \(x^2 + y^2 = 4\) in the \(xy\)-plane: $$x(t) = 2\cos t, \quad y(t) = 2\sin t, \quad t \in [0, 2\pi)$$ Substitute into the plane equation \(z = 3x - y\): $$z(t) = 3(2\cos t) - 2\sin t = 6\cos t - 2\sin t$$ Thus, the vector parametrization is: $$\mathbf{r}(t) = \langle 2\cos t, \; 2\sin t, \; 6\cos t - 2\sin t \rangle, \quad t \in [0, 2\pi)$$

Problem 2

[12 points]

Consider the curve given by \(\mathbf{r}(t) = \langle 4\cos t, \; 4\sin t, \; 3t \rangle\).

  1. Find the velocity vector \(\mathbf{r}'(t)\) and compute the speed \(\|\mathbf{r}'(0)\|\) at \(t = 0\).
  2. Find parametric equations for the tangent line to the curve at \(t = 0\).
View Solution
  1. Differentiate component-wise: $$\mathbf{r}'(t) = \langle -4\sin t, \; 4\cos t, \; 3 \rangle$$ At \(t = 0\): $$\mathbf{r}'(0) = \langle -4\sin(0), \; 4\cos(0), \; 3 \rangle = \langle 0, 4, 3 \rangle$$ The speed at \(t = 0\) is: $$\|\mathbf{r}'(0)\| = \sqrt{0^2 + 4^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = 5$$
  2. The base point on the curve at \(t = 0\) is: $$\mathbf{r}(0) = \langle 4\cos(0), \; 4\sin(0), \; 3(0) \rangle = \langle 4, 0, 0 \rangle$$ Using direction vector \(\mathbf{v} = \mathbf{r}'(0) = \langle 0, 4, 3 \rangle\) and parameter \(s \in \mathbb{R}\): $$x(s) = 4, \quad y(s) = 4s, \quad z(s) = 3s$$

Quiz 3: Arc Length, Scalar Line Integrals, and Projectile Motion

Date: 09/08/2026

Problem 1

[8 points]

A thin metallic wire is shaped along the circular helix

$$\mathbf{r}(t) = \langle 4\cos t, \; 4\sin t, \; 3t \rangle, \qquad 0 \le t \le \pi$$
  1. Find the differential arc length element \(ds = \|\mathbf{r}'(t)\|\,dt\).
  2. If the wire has linear mass density \(\rho(x, y, z) = 2z\), evaluate the scalar line integral $$M = \int_C \rho(x, y, z)\,ds$$ to calculate the total mass of the wire.
View Solution
  1. Differentiate component-wise: $$\mathbf{r}'(t) = \langle -4\sin t, \; 4\cos t, \; 3 \rangle$$ The speed along the helix is: $$\|\mathbf{r}'(t)\| = \sqrt{(-4\sin t)^2 + (4\cos t)^2 + 3^2} = \sqrt{16(\sin^2 t + \cos^2 t) + 9} = \sqrt{16 + 9} = 5$$ Thus, the arc length element is: $$ds = \|\mathbf{r}'(t)\|\,dt = 5\,dt$$
  2. Along the curve, the density is \(\rho(\mathbf{r}(t)) = 2z(t) = 2(3t) = 6t\).
    Evaluating the scalar line integral: $$\begin{aligned} M &= \int_0^\pi \rho(\mathbf{r}(t))\,\|\mathbf{r}'(t)\|\,dt \\ &= \int_0^\pi (6t)(5)\,dt \\ &= \int_0^\pi 30t\,dt \\ &= \left[ 15t^2 \right]_0^\pi = 15\pi^2 \end{aligned}$$

Problem 2

[12 points]

A projectile is launched from the origin \((0, 0, 0)\) with an initial velocity of

$$\mathbf{v}(0) = \langle 20, \; 0, \; 30 \rangle \quad \text{(in m/s)}$$

The only acceleration acting on the projectile is downward gravity \(\mathbf{a}(t) = \langle 0, 0, -10 \rangle\text{ m/s}^2\) (neglecting air resistance).

  1. Find the velocity vector \(\mathbf{v}(t)\) and position vector \(\mathbf{r}(t)\) for all \(t \ge 0\).
  2. Find the time \(T\) when the projectile impacts the ground (\(z = 0\)), and determine its horizontal distance from the origin at that time.
  3. Find the maximum height \(H\) reached by the projectile during flight.
View Solution
  1. Integrate acceleration to find velocity: $$\mathbf{v}(t) = \int \mathbf{a}(t)\,dt = \langle 0, 0, -10t \rangle + \mathbf{C}_1$$ Using \(\mathbf{v}(0) = \langle 20, 0, 30 \rangle\), we have \(\mathbf{C}_1 = \langle 20, 0, 30 \rangle\): $$\mathbf{v}(t) = \langle 20, \; 0, \; 30 - 10t \rangle$$ Integrate velocity with initial position \(\mathbf{r}(0) = \langle 0, 0, 0 \rangle\): $$\mathbf{r}(t) = \int \mathbf{v}(t)\,dt = \langle 20t, \; 0, \; 30t - 5t^2 \rangle$$
  2. Set the vertical position component to zero: $$z(T) = 30T - 5T^2 = 0 \implies 5T(6 - T) = 0$$ Since \(T > 0\), the flight time is \(T = 6\text{ s}\).
    At impact, the horizontal distance along the \(x\)-axis is: $$x(6) = 20(6) = 120\text{ m}$$
  3. Maximum height occurs when the vertical velocity is zero: $$v_z(t) = 30 - 10t = 0 \implies t = 3\text{ s}$$ Evaluating the vertical position at \(t = 3\): $$H = z(3) = 30(3) - 5(3)^2 = 90 - 45 = 45\text{ m}$$

Quiz 4: Level Curves, Chain Rule, and Implicit Differentiation

Date: 09/15/2026

Problem 1

[8 points]

Consider the surface given by the equation

$$z = 16 - x^2 - y^2$$
  1. Find the equation of the level curve corresponding to \(z = 7\). Identify the geometric shape of this curve in the \(xy\)-plane, specifying its center and radius.
  2. Find the equation of the level curve corresponding to \(z = 16\). Describe what this level curve represents in the \(xy\)-plane, and explain why there are no real level curves for \(z > 16\).
View Solution
  1. Substitute \(z = 7\) into the surface equation: $$16 - x^2 - y^2 = 7 \implies x^2 + y^2 = 16 - 7 \implies x^2 + y^2 = 9$$ In the \(xy\)-plane, this is a circle centered at the origin \((0, 0)\) with radius \(r = \sqrt{9} = 3\).
  2. Substitute \(z = 16\) into the surface equation: $$16 - x^2 - y^2 = 16 \implies x^2 + y^2 = 0$$ The only real solution is the single point \((0, 0)\) at the origin (representing the maximum peak of the paraboloid).

    For \(z > 16\), we have \(x^2 + y^2 = 16 - z < 0\). Since the sum of squares of real numbers cannot be negative, there are no real points on the surface above \(z = 16\).

Problem 2

[12 points]

Answer the following questions regarding the Chain Rule and implicit differentiation:

  1. Let \(z = x^2 y + 2x\), where \(x(t) = e^t\) and \(y(t) = \sin t\).
    1. Write down the multivariable Chain Rule formula for \(\dfrac{dz}{dt}\) in terms of partial and ordinary derivatives.
    2. Compute the numerical value of \(\dfrac{dz}{dt}\) at \(t = 0\).
  2. The equation $$x^2 y + z^3 - 3z = 5$$ defines \(z\) implicitly as a differentiable function of \(x\) and \(y\) (that is, \(z = z(x, y)\)). Find \(\dfrac{\partial z}{\partial x}\) in terms of \(x, y,\) and \(z\).
View Solution
    1. The Chain Rule formula is: $$\frac{dz}{dt} = \frac{\partial z}{\partial x}\frac{dx}{dt} + \frac{\partial z}{\partial y}\frac{dy}{dt}$$
    2. Compute the component derivatives: $$\frac{\partial z}{\partial x} = 2xy + 2, \qquad \frac{\partial z}{\partial y} = x^2$$ $$\frac{dx}{dt} = e^t, \qquad \frac{dy}{dt} = \cos t$$ At \(t = 0\), we have: $$x(0) = e^0 = 1, \qquad y(0) = \sin(0) = 0$$ Evaluating the derivatives at \(t = 0\): $$\frac{\partial z}{\partial x}(1, 0) = 2(1)(0) + 2 = 2, \qquad \frac{\partial z}{\partial y}(1, 0) = 1^2 = 1$$ $$\frac{dx}{dt}(0) = e^0 = 1, \qquad \frac{dy}{dt}(0) = \cos(0) = 1$$ Substitute into the Chain Rule: $$\left.\frac{dz}{dt}\right|_{t=0} = (2)(1) + (1)(1) = 2 + 1 = 3$$
  2. Method 1 (Formula): Define \(F(x, y, z) = x^2 y + z^3 - 3z - 5 = 0\).
    Compute the required partial derivatives: $$F_x = 2xy, \qquad F_z = 3z^2 - 3$$ Applying \(\dfrac{\partial z}{\partial x} = -\dfrac{F_x}{F_z}\): $$\frac{\partial z}{\partial x} = -\frac{2xy}{3z^2 - 3} \quad \left(\text{or } \frac{2xy}{3 - 3z^2}\right)$$
    Method 2 (Direct Implicit Differentiation): Differentiating both sides with respect to \(x\) (treating \(y\) as a constant and \(z\) as a function of \(x\)): $$2xy + 3z^2\frac{\partial z}{\partial x} - 3\frac{\partial z}{\partial x} = 0 \implies (3z^2 - 3)\frac{\partial z}{\partial x} = -2xy \implies \frac{\partial z}{\partial x} = -\frac{2xy}{3z^2 - 3}$$
