Lesson 1: Review of Vectors & Geometry

Goals

  • Define what a vector is.
  • Add vectors.
  • Find the length (magnitude) of a vector.
  • Understand unit vectors and direction.

Definition: Vector

A vector is a mathematical object that has both:

  1. Magnitude — i.e., length;
  2. Direction — i.e., where it points.

Vectors are used to represent physical quantities that are not fully described by a single real number (scalar), such as velocity and force.

The vector \(\overrightarrow{AB}\) starting from point \(A=(a_1,a_2,a_3)\) to point \(B=(b_1,b_2,b_3)\) is given by:

\[ \overrightarrow{AB} = \langle b_1-a_1,\ b_2-a_2,\ b_3-a_3 \rangle \]

The magnitude (length) of a vector \(\vec{u} = \langle u_1,\ u_2,\ u_3 \rangle\) is:

\[ \|\vec{u}\| = \sqrt{u_1^2 + u_2^2 + u_3^2} \]

Example 1

Let \(A=(1,2,3)\) and \(B=(4,6,3)\).

  1. Find the vector \(\overrightarrow{AB}\).
  2. Compute its magnitude.

Vector Addition & Scalar Multiplication

Two vectors \(\vec{u}\) and \(\vec{v}\) can be added by adding their corresponding coordinate components (coordinate-wise). Geometrically, this corresponds to the triangle rule for vector addition.

Example 2

Find the sum of \(\vec{u}=\langle 1,2\rangle\) and \(\vec{v}=\langle 3,-5\rangle\).

Solution

\[ \vec{u}+\vec{v} = \langle 1+3,\ 2+(-5) \rangle = \langle 4,\ -3 \rangle \]

Scalar Multiplication

If \(\lambda \in \mathbb{R}\) is a scalar (a real number) and \(\vec{u}\) is a vector, then the scalar multiple \(\lambda\vec{u}\) is the vector whose length is \(|\lambda|\) times the length of \(\vec{u}\), and its direction is:

  • The same as \(\vec{u}\) if \(\lambda > 0\).
  • Opposite to \(\vec{u}\) if \(\lambda < 0\).

Component-wise: if \(\vec{u}=\langle u_1, u_2, u_3 \rangle\), then \(\lambda\vec{u} = \langle \lambda u_1, \lambda u_2, \lambda u_3 \rangle\).

Standard Basis Vectors

The vectors \(\hat{i}=\langle 1,0,0\rangle\), \(\hat{j}=\langle 0,1,0\rangle\), and \(\hat{k}=\langle 0,0,1\rangle\) are the standard basis vectors of \(\mathbb{R}^3\).

Example 3

Let \(\vec{u}=\hat{i}-2\hat{j}+\hat{k}\) and \(\vec{v}=2\hat{i}+3\hat{j}-\hat{k}\). Find \(2\vec{u}+3\vec{v}\).

Solution

\[ \begin{aligned} 2\vec{u}+3\vec{v} &= 2(\hat{i}-2\hat{j}+\hat{k}) + 3(2\hat{i}+3\hat{j}-\hat{k}) \\ &= (2\hat{i}-4\hat{j}+2\hat{k}) + (6\hat{i}+9\hat{j}-3\hat{k}) \\ &= 8\hat{i}+5\hat{j}-\hat{k}. \end{aligned} \]

Unit Vectors

Definition: Unit Vector

A vector \(\vec{u}\) is called a unit vector if its magnitude is equal to \(1\) — i.e., \(\|\vec{u}\|=1\).

Key Formula: For any non-zero vector \(\vec{w}\), the unit vector in the same direction as \(\vec{w}\) is:

\[ \hat{w} = \frac{\vec{w}}{\|\vec{w}\|} \]

Example 4

  1. Find a unit vector in the direction of \(\vec{u}=\langle -5, 4\rangle\).
  2. Find a unit vector in the direction of \(\vec{w}=6\hat{i}-3\hat{j}+4\hat{k}\).

Solution

  1. \(\|\vec{u}\| = \sqrt{(-5)^2 + 4^2} = \sqrt{25 + 16} = \sqrt{41}\)
    \(\hat{u} = \frac{\vec{u}}{\|\vec{u}\|} = \left\langle \frac{-5}{\sqrt{41}},\ \frac{4}{\sqrt{41}} \right\rangle\)
  2. \(\|\vec{w}\| = \sqrt{6^2 + (-3)^2 + 4^2} = \sqrt{36 + 9 + 16} = \sqrt{61}\)
    \(\hat{w} = \frac{\vec{w}}{\|\vec{w}\|} = \frac{6}{\sqrt{61}}\hat{i} - \frac{3}{\sqrt{61}}\hat{j} + \frac{4}{\sqrt{61}}\hat{k}\)

Applied Problem: River Crossing

Problem

A kayaker starts from the south bank of a straight river flowing due east at \(4\text{ mph}\). The kayak's speed relative to the water is \(8\text{ mph}\).

  1. In what direction should the kayaker head to land straight across the river on the north bank?
  2. If the river is \(0.75\text{ miles}\) wide, how long will the crossing take?

Solution

  1. To land straight north, the westward component of the kayak's velocity must cancel the river's \(4\text{ mph}\) eastward flow.
    Set \(\vec{v}_{\text{kayak}} = \langle -x, y \rangle\) with \(x^2+y^2=8^2\). The horizontal component must satisfy \(x=4\), so \(y=\sqrt{64-16}=4\sqrt{3}\). Thus the kayaker should aim west of north at angle \(\theta = \arcsin(4/8)=30^\circ\) upstream.
  2. The ground speed directly across (north) is \(4\sqrt{3}\text{ mph}\). For width \(d = 0.75\text{ mi}\): \[ t = \frac{0.75}{4\sqrt{3}} = \frac{3}{16\sqrt{3}}\text{ hr} \approx 0.108\text{ hr} \approx 6.5\text{ min}. \]
