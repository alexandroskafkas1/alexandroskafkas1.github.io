Recitation 1: Approximating Areas, Definite Integrals, and FTC

Problem 1: Riemann Sums & Monotonicity

Consider the function \(f(x) = 12 - x^2\) on the interval \([0, 3]\).

  1. Divide \([0, 3]\) into \(n = 3\) equal subintervals. Determine the subinterval width \(\Delta x\) and list the partition points \(x_0, x_1, x_2, x_3\).
  2. Compute the Right-endpoint approximation \(R_3\) for the area under the curve.
  3. Is \(R_3\) an overestimate or an underestimate of the true area under \(f(x)\) on \([0, 3]\)? Explain using the monotonicity of \(f(x)\).
View Solution
  1. The subinterval width is: $$\Delta x = \frac{b - a}{n} = \frac{3 - 0}{3} = 1$$ The partition grid points are: $$x_0 = 0, \quad x_1 = 1, \quad x_2 = 2, \quad x_3 = 3$$
  2. The right endpoints are \(x_1 = 1\), \(x_2 = 2\), and \(x_3 = 3\): $$\begin{aligned} R_3 &= \sum_{i=1}^3 f(x_i)\,\Delta x = \left[ f(1) + f(2) + f(3) \right] \cdot 1 \\ &= (12 - 1^2) + (12 - 2^2) + (12 - 3^2) \\ &= 11 + 8 + 3 = 22 \end{aligned}$$
  3. Since \(f'(x) = -2x \le 0\) on \([0, 3]\), the function \(f(x)\) is decreasing on the interval. For a decreasing function, the right endpoint always attains the minimum value on each subinterval, which makes \(R_3\) an underestimate.

Problem 2: Geometric Integrals & Properties

Evaluate the following definite integrals using geometric formulas and basic properties of integrals:

  1. \(\displaystyle \int_{-3}^3 \left( 2\sqrt{9 - x^2} - 4 \right) dx\)
  2. If \(\displaystyle \int_{-1}^5 f(x)\,dx = 14\) and \(\displaystyle \int_{2}^5 f(x)\,dx = -3\), find the value of \(\displaystyle \int_{-1}^2 3f(x)\,dx\).
View Solution
  1. Using the sum/difference and constant multiple properties: $$\int_{-3}^3 \left( 2\sqrt{9 - x^2} - 4 \right) dx = 2\int_{-3}^3 \sqrt{9 - x^2}\,dx - \int_{-3}^3 4\,dx$$ The term \(\int_{-3}^3 \sqrt{9 - x^2}\,dx\) represents the area of a semicircle with radius \(r = 3\): $$\text{Area} = \frac{1}{2}\pi r^2 = \frac{1}{2}\pi (3^2) = \frac{9\pi}{2}$$ By the Constant Rule, \(\int_{-3}^3 4\,dx = 4(3 - (-3)) = 24\). Thus: $$\int_{-3}^3 \left( 2\sqrt{9 - x^2} - 4 \right) dx = 2\left(\frac{9\pi}{2}\right) - 24 = 9\pi - 24$$
  2. By interval additivity: $$\int_{-1}^5 f(x)\,dx = \int_{-1}^2 f(x)\,dx + \int_2^5 f(x)\,dx$$ Substituting the given values: $$14 = \int_{-1}^2 f(x)\,dx + (-3) \implies \int_{-1}^2 f(x)\,dx = 17$$ Applying the Constant Multiple Rule: $$\int_{-1}^2 3f(x)\,dx = 3 \int_{-1}^2 f(x)\,dx = 3(17) = 51$$

Problem 3: Fundamental Theorem of Calculus, Part 1

Find the derivative \(\displaystyle \frac{dy}{dx}\) for each of the following functions using the Fundamental Theorem of Calculus, Part 1 (FTC 1):

  1. \(y = \displaystyle \int_x^4 \frac{t^2}{1 + \cos^2(t)}\,dt\)
  2. \(y = \displaystyle \int_{0}^{x^3} \sqrt{1 + 2t^2}\,dt\)
  3. \(y = \displaystyle \int_{2x}^{x^2} \tan(t)\,dt\)
View Solution
  1. Reversing the limits of integration introduces a negative sign: $$y = -\int_4^x \frac{t^2}{1 + \cos^2(t)}\,dt \implies \frac{dy}{dx} = -\frac{x^2}{1 + \cos^2(x)}$$
  2. Let \(u(x) = x^3\). Applying FTC 1 along with the Chain Rule: $$\frac{dy}{dx} = \sqrt{1 + 2(x^3)^2} \cdot \frac{d}{dx}(x^3) = 3x^2\sqrt{1 + 2x^6}$$
  3. Split the integral at a constant (e.g., \(c = 0\)): $$y = \int_{2x}^0 \tan(t)\,dt + \int_0^{x^2} \tan(t)\,dt = -\int_0^{2x} \tan(t)\,dt + \int_0^{x^2} \tan(t)\,dt$$ Differentiating both parts using the Chain Rule: $$\begin{aligned} \frac{dy}{dx} &= -\tan(2x)\cdot \frac{d}{dx}(2x) + \tan(x^2)\cdot \frac{d}{dx}(x^2) \\ &= 2x\tan(x^2) - 2\tan(2x) \end{aligned}$$

Problem 4: Evaluating Integrals with FTC 2

Evaluate each definite integral algebraically using the Fundamental Theorem of Calculus, Part II (FTC 2):

  1. \(\displaystyle \int_1^4 \frac{3x^2 - 2\sqrt{x}}{x}\,dx\)
  2. \(\displaystyle \int_0^{\pi/4} \left( \sec^2\theta + 4\cos\theta \right) d\theta\)
View Solution
  1. Rewrite the integrand by dividing each term by \(x\): $$\frac{3x^2 - 2x^{1/2}}{x} = 3x - 2x^{-1/2}$$ Applying the Power Rule: $$\begin{aligned} \int_1^4 \left( 3x - 2x^{-1/2} \right) dx &= \left[ \frac{3}{2}x^2 - 4x^{1/2} \right]_1^4 \\ &= \left( \frac{3}{2}(4)^2 - 4\sqrt{4} \right) - \left( \frac{3}{2}(1)^2 - 4\sqrt{1} \right) \\ &= (24 - 8) - \left( \frac{3}{2} - 4 \right) \\ &= 16 - \left(-\frac{5}{2}\right) = \frac{37}{2} \end{aligned}$$
  2. Antidifferentiating term-by-term: $$\begin{aligned} \int_0^{\pi/4} \left( \sec^2\theta + 4\cos\theta \right) d\theta &= \left[ \tan\theta + 4\sin\theta \right]_0^{\pi/4} \\ &= \left( \tan\left(\frac{\pi}{4}\right) + 4\sin\left(\frac{\pi}{4}\right) \right) - \left( \tan(0) + 4\sin(0) \right) \\ &= \left( 1 + 4\cdot\frac{\sqrt{2}}{2} \right) - 0 = 1 + 2\sqrt{2} \end{aligned}$$

Problem 5: Area Accumulation Functions

Let \(g(x) = \displaystyle \int_0^x f(t)\,dt\) for \(x \in [0, 6]\), where the graph of \(f(t)\) consists of two line segments: from \((0, 2)\) to \((4, -2)\), and from \((4, -2)\) to \((6, 0)\).

  1. Find the values of \(g(0)\) and \(g(2)\).
  2. At what point \(x \in (0, 6)\) does \(g(x)\) attain its absolute maximum? Justify your answer using \(g'(x)\).
View Solution
  1. Evaluating at the endpoints:
    • \(g(0) = \displaystyle \int_0^0 f(t)\,dt = 0\).
    • The line segment connecting \((0, 2)\) to \((4, -2)\) has the equation \(y = -\frac{4}{4}t + 2 = 2 - t\), which crosses the \(t\)-axis at \(t = 2\). On \([0, 2]\), the region is a triangle with base \(2\) and height \(2\): $$g(2) = \frac{1}{2}(2)(2) = 2$$
  2. By FTC 1, \(g'(x) = f(x)\):
    • For \(x \in (0, 2)\), \(g'(x) = f(x) > 0\), so \(g(x)\) is increasing.
    • For \(x \in (2, 6)\), \(g'(x) = f(x) < 0\), so \(g(x)\) is decreasing.
    Therefore, \(g(x)\) achieves its absolute maximum at \(x = 2\).

Recitation 2: Net Change, Substitution, and Areas Between Curves

Problem 1: Displacement vs. Total Distance Traveled

A particle moves along a horizontal line with velocity \(v(t) = 3t^2 - 12t + 9\) (in \(\text{m/s}\)) for \(t \in [0, 4]\).

  1. Find the displacement of the particle over the time interval \([0, 4]\).
  2. Find the total distance traveled by the particle over \([0, 4]\).
View Solution
  1. By the Net Change Theorem, displacement is the definite integral of velocity: $$\begin{aligned} \text{Displacement} &= \int_0^4 (3t^2 - 12t + 9)\,dt = \left[ t^3 - 6t^2 + 9t \right]_0^4 \\ &= (4^3 - 6(4^2) + 9(4)) - 0 = 64 - 96 + 36 = 4\text{ meters} \end{aligned}$$
  2. Find turning points where \(v(t) = 0\): $$v(t) = 3(t^2 - 4t + 3) = 3(t - 1)(t - 3) = 0 \implies t = 1, \; t = 3$$
    • On \((0, 1)\): \(v(t) > 0\) (moving right)
    • On \((1, 3)\): \(v(t) < 0\) (moving left)
    • On \((3, 4)\): \(v(t) > 0\) (moving right)
    Split the integral and evaluate each segment: $$\int_0^1 v(t)\,dt = \left[ t^3 - 6t^2 + 9t \right]_0^1 = 4$$ $$\int_1^3 v(t)\,dt = \left[ t^3 - 6t^2 + 9t \right]_1^3 = 0 - 4 = -4$$ $$\int_3^4 v(t)\,dt = \left[ t^3 - 6t^2 + 9t \right]_3^4 = 4 - 0 = 4$$ $$\text{Total Distance} = |4| + |-4| + |4| = 4 + 4 + 4 = 12\text{ meters}$$

Problem 2: Definite Substitution & Algebraic Back-Substitution

Evaluate the definite integral:

$$\int_0^3 x\sqrt{x + 1}\,dx$$
View Solution

Let \(u = x + 1 \implies x = u - 1\) and \(du = dx\).

Transform the limits of integration:

  • Lower limit: \(x = 0 \implies u = 0 + 1 = 1\)
  • Upper limit: \(x = 3 \implies u = 3 + 1 = 4\)
$$\begin{aligned} \int_0^3 x\sqrt{x + 1}\,dx &= \int_1^4 (u - 1)\sqrt{u}\,du = \int_1^4 \left( u^{3/2} - u^{1/2} \right) du \\ &= \left[ \frac{2}{5}u^{5/2} - \frac{2}{3}u^{3/2} \right]_1^4 \\ &= \left( \frac{2}{5}(4^{5/2}) - \frac{2}{3}(4^{3/2}) \right) - \left( \frac{2}{5}(1^{5/2}) - \frac{2}{3}(1^{3/2}) \right) \\ &= \left( \frac{64}{5} - \frac{16}{3} \right) - \left( \frac{2}{5} - \frac{2}{3} \right) = \frac{112}{15} - \left(-\frac{4}{15}\right) = \frac{116}{15} \end{aligned}$$

Problem 3: Indefinite Substitution into Inverse Tangent

Evaluate the indefinite integral:

$$\int \frac{x}{1 + x^4}\,dx$$
View Solution

Rewrite the integrand as \(\displaystyle\int \frac{x}{1 + (x^2)^2}\,dx\).

Problem 4: Area Between Curves via Horizontal Slicing

Find the area of the region enclosed by the curves \(x = 3 - y^2\) and \(x = y + 1\).

View Solution

Step 1: Find points of intersection in \(y\):

$$3 - y^2 = y + 1 \implies y^2 + y - 2 = 0 \implies (y + 2)(y - 1) = 0 \implies y = -2, \; y = 1$$

Step 2: Compare boundaries: For \(y = 0 \in (-2, 1)\), \(x_{\text{right}} = 3 - y^2\) and \(x_{\text{left}} = y + 1\).

Step 3: Integrate with respect to \(y\):

$$\begin{aligned} A &= \int_{-2}^1 \left[ (3 - y^2) - (y + 1) \right] dy = \int_{-2}^1 (2 - y - y^2)\,dy \\ &= \left[ 2y - \frac{y^2}{2} - \frac{y^3}{3} \right]_{-2}^1 \\ &= \left( 2 - \frac{1}{2} - \frac{1}{3} \right) - \left( 2(-2) - \frac{(-2)^2}{2} - \frac{(-2)^3}{3} \right) \\ &= \frac{7}{6} - \left( -4 - 2 + \frac{8}{3} \right) = \frac{7}{6} - \left(-\frac{10}{3}\right) = \frac{7}{6} + \frac{20}{6} = \frac{27}{6} = \frac{9}{2} \end{aligned}$$

Recitation 3: Volumes of Solids: Cross-Sections, Disks, Washers, and Shells

Problem 1: Slicing with Equilateral Triangle Cross-Sections

The base of a solid is the region in the \(xy\)-plane bounded by the parabola \(y = 4 - x^2\) and the \(x\)-axis. Cross-sections of the solid perpendicular to the \(x\)-axis are equillateral triangles with one side lying in the base.

  1. Express the base side length \(s(x)\) of an arbitrary cross-section at position \(x\).
  2. Find the cross-sectional area function \(A(x)\).
  3. Set up and evaluate a definite integral to determine the total volume of the solid.
View Solution
  1. The base region intersects the \(x\)-axis where \(4 - x^2 = 0 \implies x = \pm 2\). For any \(x \in [-2, 2]\), the vertical strip extends from \(y = 0\) to \(y = 4 - x^2\). Thus, the side length of the equilateral triangle cross-section is: $$s(x) = (4 - x^2) - 0 = 4 - x^2$$
  2. The area of an equilateral triangle with side length \(s\) is \(A = \frac{\sqrt{3}}{4}s^2\). Substituting \(s(x) = 4 - x^2\): $$A(x) = \frac{\sqrt{3}}{4}[s(x)]^2 = \frac{\sqrt{3}}{4}(4 - x^2)^2 = \frac{\sqrt{3}}{4}(16 - 8x^2 + x^4)$$
  3. By the cross-sectional slicing principle, integrating from \(x = -2\) to \(x = 2\) and utilizing symmetry: $$\begin{aligned} V &= \int_{-2}^2 A(x)\,dx = 2 \int_0^2 \frac{\sqrt{3}}{4}(16 - 8x^2 + x^4)\,dx \\ &= \frac{\sqrt{3}}{2} \left[ 16x - \frac{8}{3}x^3 + \frac{x^5}{5} \right]_0^2 \\ &= \frac{\sqrt{3}}{2} \left( 32 - \frac{64}{3} + \frac{32}{5} \right) \\ &= \frac{\sqrt{3}}{2} \left( \frac{480 - 320 + 96}{15} \right) = \frac{\sqrt{3}}{2} \left( \frac{256}{15} \right) = \frac{128\sqrt{3}}{15} \end{aligned}$$

Problem 2: Disks vs. Washers on Shifted Axes

Let \(\mathcal{R}\) be the planar region bounded by the curves \(y = \sqrt{x}\), \(y = 2\), and the \(y\)-axis (\(x = 0\)).

  1. Use the Disk Method (integrating with respect to \(y\)) to compute the volume of the solid generated by rotating \(\mathcal{R}\) about the \(y\)-axis.
  2. Use the Washer Method (integrating with respect to \(x\)) to compute the volume of the solid generated by revolving \(\mathcal{R}\) about the horizontal line \(y = 2\).
View Solution
  1. The curves intersetc where \(\sqrt{x} = 2 \implies x = 4\), with \(y\) spanning the interval \([0, 2]\). Rotating about the vertical \(y\)-axis, horizontal cross-sections are circular disks of thickness \(dy\). Expressing \(x\) in terms of \(y\): $$y = \sqrt{x} \implies x = y^2$$ The disk radius is \(R(y) = y^2 - 0 = y^2\). The volume is: $$V = \pi \int_0^2 [R(y)]^2\,dy = \pi \int_0^2 (y^2)^2\,dy = \pi \int_0^2 y^4\,dy = \pi \left[ \frac{y^5}{5} \right]_0^2 = \frac{32\pi}{5}$$
  2. When revolving \(\mathcal{R}\) about the upper boundary \(y = 2\), vertical slices of thickness \(dx\) create circular disks (with zero inner radius) across \(x \in [0, 4]\). The radius is: $$R(x) = y_{\text{axis}} - y_{\text{bottom}} = 2 - \sqrt{x}$$ The resulting volume is: $$\begin{aligned} V &= \pi \int_0^4 [R(x)]^2\,dx = \pi \int_0^4 (2 - \sqrt{x})^2\,dx \\ &= \pi \int_0^4 (4 - 4x^{1/2} + x)\,dx \\ &= \pi \left[ 4x - \frac{8}{3}x^{3/2} + \frac{x^2}{2} \right]_0^4 \\ &= \pi \left( 16 - \frac{8}{3}(8) + 8 \right) = \pi \left( 24 - \frac{64}{3} \right) = \frac{8\pi}{3} \end{aligned}$$

Problem 3: The Washer Method on Shifted Axes

Consider the finite region \(\mathcal{R}\) enclosed between the parabola \(y = 2x - x^2\) and the line \(y = x\).

  1. Determine the intersection points of the two curves.
  2. Set up and evaluate an integral using the Washer Method for the volume obtained by revolving \(\mathcal{R}\) about the \(x\)-axis.
  3. Set up and evaluate an integral using the Washer Method for the volume obtained by revolving \(\mathcal{R}\) about the horizontal line \(y = -1\).
View Solution
  1. Equating the functions: $$2x - x^2 = x \implies x - x^2 = 0 \implies x(1 - x) = 0 \implies x = 0 \quad \text{and} \quad x = 1$$ On the interval \((0, 1)\), \(2x - x^2 > x\), so \(y_{\text{top}} = 2x - x^2\) and \(y_{\text{bottom}} = x\).
  2. Revolved about the \(x\)-axis (\(y = 0\)): $$R_{\text{outer}}(x) = 2x - x^2, \quad r_{\text{inner}}(x) = x$$ Evaluating the washer integral: $$\begin{aligned} V &= \pi \int_0^1 \left( [R_{\text{outer}}(x)]^2 - [r_{\text{inner}}(x)]^2 \right) dx \\ &= \pi \int_0^1 \left( (2x - x^2)^2 - x^2 \right) dx \\ &= \pi \int_0^1 \left( 4x^2 - 4x^3 + x^4 - x^2 \right) dx = \pi \int_0^1 \left( x^4 - 4x^3 + 3x^2 \right) dx \\ &= \pi \left[ \frac{x^5}{5} - x^4 + x^3 \right]_0^1 = \pi \left( \frac{1}{5} - 1 + 1 \right) = \frac{\pi}{5} \end{aligned}$$
  3. Revolved about the line \(y = -1\), the radii are measured from the axis of rotation: $$\begin{aligned} R_{\text{outer}}(x) &= (2x - x^2) - (-1) = 2x - x^2 + 1 \\ r_{\text{inner}}(x) &= x - (-1) = x + 1 \end{aligned}$$ Subtracting the squared radii: $$\begin{aligned} [R_{\text{outer}}(x)]^2 - [r_{\text{inner}}(x)]^2 &= (1 + 2x - x^2)^2 - (x + 1)^2 \\ &= (1 + 4x^2 + x^4 + 4x - 2x^2 - 4x^3) - (x^2 + 2x + 1) \\ &= (x^4 - 4x^3 + 2x^2 + 4x + 1) - (x^2 + 2x + 1) \\ &= x^4 - 4x^3 + x^2 + 2x \end{aligned}$$ Integrating across \([0, 1]\): $$\begin{aligned} V &= \pi \int_0^1 (x^4 - 4x^3 + x^2 + 2x)\,dx \\ &= \pi \left[ \frac{x^5}{5} - x^4 + \frac{x^3}{3} + x^2 \right]_0^1 \\ &= \pi \left( \frac{1}{5} - 1 + \frac{1}{3} + 1 \right) = \pi \left( \frac{1}{5} + \frac{1}{3} \right) = \frac{8\pi}{15} \end{aligned}$$

Problem 4: Cylindrical Shells vs. Washer Selection

Let \(\mathcal{S}\) be the solid generated by rotating the region under \(y = \sin(x^2)\) on the interval \([0, \sqrt{\pi}]\) and above the \(x\)-axis about the \(y\)-axis.

  1. Explain why the Method of Cylindrical Shells is better suited for this volume than the Washer Method.
  2. Set up the volume integral using the Method of Cylindrical Shells.
  3. Evaluate the integral using a substitution.
View Solution
  1. Slicing perpendicular to the \(y\)-axis (the Washer Method) requires solving \(y = \sin(x^2)\) for \(x\) in terms of \(y\) (\(x = \sqrt{\arcsin y}\)), which splits into separate boundary branches and yields an inverse trigonometric integral that is difficult to evaluate directly. By contrast, Cylindrical Shells uses vertical slices of thickness \(dx\), which directly pairs the factor \(x\) from the circumference with \(x\,dx\) from the argument of \(\sin(x^2)\).
  2. For a vertical strip at coordinate \(x \in [0, \sqrt{\pi}]\): $$\text{Radius} = x - 0 = x, \quad \text{Height} = \sin(x^2) - 0 = \sin(x^2), \quad \text{Thickness} = dx$$ The volume integral is: $$V = \int_0^{\sqrt{\pi}} 2\pi (\text{radius})(\text{height})\,dx = 2\pi \int_0^{\sqrt{\pi}} x\sin(x^2)\,dx$$
  3. Let \(u = x^2 \implies du = 2x\,dx \implies x\,dx = \frac{1}{2}\,du\). Transforming the integration bounds:
    • When \(x = 0 \implies u = 0^2 = 0\).
    • When \(x = \sqrt{\pi} \implies u = (\sqrt{\pi})^2 = \pi\).
    Evaluatting: $$\begin{aligned} V &= 2\pi \int_0^\pi \sin(u) \cdot \left(\frac{1}{2}\,du\right) = \pi \int_0^\pi \sin(u)\,du \\ &= \pi \Big[ -\cos(u) \Big]_0^\pi = \pi \Big( -\cos(\pi) - (-\cos(0)) \Big) \\ &= \pi \Big( -(-1) + 1 \Big) = 2\pi \end{aligned}$$

Recitation 4: Work, Pumping Liquids, and Average Value

Problem 1: Leaking Bucket Work

A \(5\text{ lb}\) bucket containing \(60\text{ lbs}\) of sand is lifted vertically from the ground to a construction platform \(20\text{ ft}\) high at a constant rate of \(2\text{ ft/s}\). Sand leaks out through a hole at a constant rate of \(1.5\text{ lb/s}\). Assuming the rope has negligible weight, find the total work done lifting the bucket to the platform.

View Solution

Let \(y\) denote the height of the bucket above the ground in feet, so \(y \in [0, 20]\).

Step 1: Determine the force function \(F(y)\).

  • At a constant speed of \(2\text{ ft/s}\), the time elapsed to reach height \(y\) is: $$t = \frac{y}{2}\text{ seconds}.$$
  • Sand leaks at \(1.5\text{ lb/s}\), so the sand lost after reaching height \(y\) is: $$\text{Sand lost} = (1.5\text{ lb/s}) \cdot \left(\frac{y}{2}\text{ s}\right) = 0.75y\text{ lbs}.$$
  • The weight of the sand remaining at height \(y\) is \(60 - 0.75y\text{ lbs}\). Adding the \(5\text{ lb}\) empty bucket gives the total force: $$F(y) = (60 - 0.75y) + 5 = 65 - 0.75y\text{ lbs}.$$

Step 2: Evaluate the work integral.

$$\begin{aligned} W &= \int_0^{20} F(y)\,dy = \int_0^{20} (65 - 0.75y)\,dy \\ &= \left[ 65y - \frac{0.75y^2}{2} \right]_0^{20} \\ &= 65(20) - 0.375(20^2) \\ &= 1300 - 150 = 1150\text{ ft-lb}. \end{aligned}$$

Problem 2: Pumping Out a Conical Tank

An inverted conical water tank (vertex pointing downward) has a total height of \(6\text{ m}\) and a top circular radius of \(2\text{ m}\). The tank is initially filled with water to a depth of \(4\text{ m}\). Find the work required to pump all of the water out over the top rim of the tank. (Use water density \(\rho = 1000\text{ kg/m}^3\) and \(g = 9.8\text{ m/s}^2\)).

View Solution

Step 1: Coordinate Setup.
Place the origin \(y = 0\) at the bottom vertex of the cone and the top rim at \(y = 6\). The water layer occupies the interval \(y \in [0, 4]\).

Step 2: Geometry of a Horizontal Slice.
At height \(y\), let \(r(y)\) be the radius of the circular water slice. By similar triangles: $$\frac{r(y)}{y} = \frac{2}{6} \implies r(y) = \frac{1}{3}y.$$ For a thin horizontal slice of thickness \(dy\): $$\begin{aligned} dV &= \pi [r(y)]^2\,dy = \pi \left(\frac{y}{3}\right)^2 dy = \frac{\pi}{9}y^2\,dy\text{ m}^3, \\ dm &= \rho\,dV = 1000 \cdot \left(\frac{\pi}{9}y^2\,dy\right) = \frac{1000\pi}{9}y^2\,dy\text{ kg}, \\ dF &= dm \cdot g = \frac{1000\pi}{9}y^2(9.8)\,dy = \frac{9800\pi}{9}y^2\,dy\text{ N}. \end{aligned}$$

Step 3: Displacement and Integration.
A slice at height \(y\) must be lifted to the rim at \(y = 6\), so the vertical displacement is \(6 - y\): $$\begin{aligned} W &= \int_0^4 dF \cdot (6 - y) = \int_0^4 \frac{9800\pi}{9}y^2(6 - y)\,dy \\ &= \frac{9800\pi}{9} \int_0^4 (6y^2 - y^3)\,dy \\ &= \frac{9800\pi}{9} \left[ 2y^3 - \frac{y^4}{4} \right]_0^4 \\ &= \frac{9800\pi}{9} \left( 2(64) - \frac{256}{4} \right) \\ &= \frac{9800\pi}{9} (128 - 64) = \frac{9800\pi(64)}{9} = \frac{627200\pi}{9}\text{ J} \approx 2.19 \times 10^5\text{ J}. \end{aligned}$$

Problem 3: Average Value via Substitution

Find the average value of the function \(f(x) = x\sqrt{x^2 + 9}\) on the interval \([0, 4]\).

View Solution

By definition, the average value of \(f(x)\) on \([a, b]\) is: $$f_{\text{avg}} = \frac{1}{b - a} \int_a^b f(x)\,dx = \frac{1}{4 - 0} \int_0^4 x\sqrt{x^2 + 9}\,dx.$$ Use the Substitution Rule:

  • Let \(u = x^2 + 9 \implies du = 2x\,dx \implies x\,dx = \frac{1}{2}\,du\).
  • When \(x = 0 \implies u = 0^2 + 9 = 9\).
  • When \(x = 4 \implies u = 4^2 + 9 = 25\).

Evaluating the definite integral: $$\begin{aligned} \int_0^4 x\sqrt{x^2 + 9}\,dx &= \frac{1}{2} \int_9^{25} u^{1/2}\,du = \frac{1}{2} \left[ \frac{2}{3}u^{3/2} \right]_9^{25} \\ &= \frac{1}{3} \left( 25^{3/2} - 9^{3/2} \right) = \frac{1}{3}(125 - 27) = \frac{98}{3}. \end{aligned}$$ Multiply by \(\frac{1}{b - a}\): $$f_{\text{avg}} = \frac{1}{4} \left( \frac{98}{3} \right) = \frac{49}{6}.$$

Problem 4: Mean Value Theorem for Integrals

Consider the function \(f(x) = 3x^2 - 2x + 1\) on \([0, 2]\).

  1. Compute the average value \(f_{\text{avg}}\) on \([0, 2]\).
  2. Find all values of \(c \in [0, 2]\) guaranteed by the Mean Value Theorem for Integrals such that \(f(c) = f_{\text{avg}}\).
View Solution
  1. First evaluate the integral: $$\begin{aligned} \int_0^2 (3x^2 - 2x + 1)\,dx &= \left[ x^3 - x^2 + x \right]_0^2 \\ &= (2^3 - 2^2 + 2) - 0 = 8 - 4 + 2 = 6. \end{aligned}$$ The average value is: $$f_{\text{avg}} = \frac{1}{2 - 0} \int_0^2 (3x^2 - 2x + 1)\,dx = \frac{1}{2}(6) = 3.$$
  2. Set \(f(c) = f_{\text{avg}} = 3\): $$3c^2 - 2c + 1 = 3 \implies 3c^2 - 2c - 2 = 0.$$ Applying the quadratic formula: $$c = \frac{-(-2) \pm \sqrt{(-2)^2 - 4(3)(-2)}}{2(3)} = \frac{2 \pm \sqrt{4 + 24}}{6} = \frac{2 \pm \sqrt{28}}{6} = \frac{1 \pm \sqrt{7}}{3}.$$ Testing each solution:
    • \(c_1 = \frac{1 + \sqrt{7}}{3} \approx \frac{1 + 2.646}{3} \approx 1.215 \in [0, 2]\).
    • \(c_2 = \frac{1 - \sqrt{7}}{3} \approx \frac{1 - 2.646}{3} \approx -0.549 \notin [0, 2]\).
    Thus, the unique value guaranteed by the theorem is \(c = \frac{1 + \sqrt{7}}{3}\).

Problem 5: Time-Weighted Averages

An electric motor runs continuously for 12 hours. During the first 4 hours (\(0 \le t \le 4\)), its average operating temperature is \(150^\circ\text{F}\). During the remaining 8 hours (\(4 < t \le 12\)), its average operating temperature is \(210^\circ\text{F}\).

  1. Find the average operating temperature of the motor across the entire 12-hour duration.
  2. Explain why the overall average is not simply \(\frac{150 + 210}{2} = 180^\circ\text{F}\).
View Solution
  1. Using the definition of average value on each subinterval: $$\begin{aligned} \frac{1}{4 - 0}\int_0^4 T(t)\,dt = 150 &\implies \int_0^4 T(t)\,dt = 4(150) = 600^\circ\text{F}\cdot\text{hr}, \\ \frac{1}{12 - 4}\int_4^{12} T(t)\,dt = 210 &\implies \int_4^{12} T(t)\,dt = 8(210) = 1680^\circ\text{F}\cdot\text{hr}. \end{aligned}$$ By interval additivity, the total accumulation over \([0, 12]\) is: $$\int_0^{12} T(t)\,dt = \int_0^4 T(t)\,dt + \int_4^{12} T(t)\,dt = 600 + 1680 = 2280^\circ\text{F}\cdot\text{hr}.$$ The overall average temperature is: $$T_{\text{avg}} = \frac{1}{12 - 0}\int_0^{12} T(t)\,dt = \frac{2280}{12} = 190^\circ\text{F}.$$
  2. The unweighted mean \(\frac{150 + 210}{2} = 180^\circ\text{F}\) assumes the motor operated at each temperature for an equal duration. However, the motor operated at \(210^\circ\text{F}\) for \(8\) hours (two-thirds of the time) and at \(150^\circ\text{F}\) for only \(4\) hours (one-third of the time). The integral computes a continuous time-weighted mean: $$T_{\text{avg}} = \frac{4}{12}(150) + \frac{8}{12}(210) = \frac{1}{3}(150) + \frac{2}{3}(210) = 50 + 140 = 190^\circ\text{F}.$$
