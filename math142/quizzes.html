Quiz 1: Riemann Sums and Fundamental Theorem of Calculus

Date: 08/25/2026

Problem 1

[8 points]

Let \(f(x) = 6 - 2x\) on the interval \([0, 2]\).

  1. Divide \([0, 2]\) into \(n = 2\) equal subintervals. Find \(\Delta x\) and list the grid points \(x_0, x_1, x_2\).
  2. Compute the Right-endpoint approximation \(R_2\) for the area under the curve.
  3. Is \(R_2\) an overestimate or an underestimate? Briefly explain using the monotonicity of \(f(x)\).
View Solution
  1. \(\Delta x = \dfrac{2 - 0}{2} = 1\). The grid points are \(x_0 = 0, \ x_1 = 1, \ x_2 = 2\).
  2. Sample at the right endpoints \(x_1 = 1\) and \(x_2 = 2\): $$R_2 = \sum_{i=1}^2 f(x_i)\Delta x = [f(1) + f(2)](1) = [(6 - 2) + (6 - 4)](1) = 4 + 2 = 6$$
  3. Since \(f'(x) = -2 \le 0\), \(f(x)\) is decreasing on \([0, 2]\). Thus, the right-endpoint approximation is an underestimate.

Problem 2

[12 points]
  1. Find the derivative \(\displaystyle\frac{dy}{dx}\) using FTC Part 1: $$y = \int_1^{x^2} \sqrt{t + 3}\,dt$$
  2. Evaluate the definite integral using FTC Part 2: $$\int_0^3 (3x^2 - 4x + 1)\,dx$$
View Solution
  1. Applying FTC 1 with the Chain Rule (\(u = x^2, \frac{du}{dx} = 2x\)): $$\frac{dy}{dx} = \sqrt{x^2 + 3} \cdot \frac{d}{dx}(x^2) = 2x\sqrt{x^2 + 3}$$
  2. Find the antiderivative and evaluate from \(0\) to \(3\): $$\begin{aligned} \int_0^3 (3x^2 - 4x + 1)\,dx &= \left[ x^3 - 2x^2 + x \right]_0^3 \\ &= (3^3 - 2(3^2) + 3) - (0^3 - 2(0^2) + 0) \\ &= (27 - 18 + 3) - 0 = 12 \end{aligned}$$

Quiz 2: Distance/Displacement, Substitution Rule, and Area Between Curves

Date: 09/01/2026

Problem 1

[8 points]

A particle moves along a straight line with velocity function \(v(t) = 6 - 2t\) (in \(\text{m/s}\)) for \(0 \le t \le 4\). Find the total distance traveled by the particle over the time interval \([0, 4]\).

View Solution
  1. The displacement is the definite integral of velocity: $$\text{Displacement} = \int_0^4 (6 - 2t)\,dt = \left[ 6t - t^2 \right]_0^4 = (6(4) - 4^2) - 0 = 24 - 16 = 8\text{ meters}$$
  2. Find the turning point by setting \(v(t) = 0\): $$6 - 2t = 0 \implies t = 3$$ On \([0, 3]\), \(v(t) \ge 0\) (forward motion), and on \([3, 4]\), \(v(t) \le 0\) (backward motion). Split the integral at \(t = 3\): $$\begin{aligned} \int_0^3 (6 - 2t)\,dt &= \left[ 6t - t^2 \right]_0^3 = (18 - 9) - 0 = 9, \\ \int_3^4 (6 - 2t)\,dt &= \left[ 6t - t^2 \right]_3^4 = (24 - 16) - (18 - 9) = 8 - 9 = -1 \end{aligned}$$ $$\text{Total Distance} = |9| + |-1| = 9 + 1 = 10\text{ meters}$$

Problem 2

[12 points]
  1. Evaluate the definite integral using the Substitution Rule: $$\int_0^1 x(x^2 + 1)^3\,dx$$
  2. Find the area of the region enclosed between the curve \(y = \sqrt{x}\) and the line \(y = x\).
View Solution
  1. Let \(u = x^2 + 1\), so \(du = 2x\,dx \implies x\,dx = \frac{1}{2}\,du\).
    Transform the limits of integration:
    • Lower limit: \(x = 0 \implies u = 0^2 + 1 = 1\)
    • Upper limit: \(x = 1 \implies u = 1^2 + 1 = 2\)
    Evaluating the integral: $$\int_0^1 x(x^2 + 1)^3\,dx = \frac{1}{2}\int_1^2 u^3\,du = \frac{1}{2}\left[ \frac{u^4}{4} \right]_1^2 = \frac{1}{2}\left( \frac{16}{4} - \frac{1}{4} \right) = \frac{1}{2}\left(\frac{15}{4}\right) = \frac{15}{8}$$
  2. Step 1 (Intersection Points): Set \(\sqrt{x} = x \implies x = x^2 \implies x(x - 1) = 0 \implies x = 0\) and \(x = 1\).

    Step 2 (Top vs. Bottom): For \(x \in (0, 1)\), testing \(x = \frac{1}{4}\) gives \(\sqrt{1/4} = \frac{1}{2} > \frac{1}{4}\), so \(y_{\text{top}} = \sqrt{x}\) and \(y_{\text{bottom}} = x\).

    Step 3 (Integrate): $$A = \int_0^1 (\sqrt{x} - x)\,dx = \left[ \frac{2}{3}x^{3/2} - \frac{x^2}{2} \right]_0^1 = \left( \frac{2}{3}(1) - \frac{1}{2}(1) \right) - 0 = \frac{2}{3} - \frac{1}{2} = \frac{1}{6}$$

Quiz 3: Volumes by Cross-Sections, Disk Method, and Cylindrical Shells

Date: 09/08/2026

Problem 1

[8 points]

The base of a solid is the region in the \(xy\)-plane bounded by the line \(y = 3 - x\), the \(x\)-axis, and the \(y\)-axis (for \(0 \le x \le 3\)). Cross-sections perpendicular to the \(x\)-axis are squares with one side lying in the base.

  1. Find the side length \(s(x)\) and the cross-sectional area \(A(x)\) of a slice at position \(x\).
  2. Find the volume of the solid.
View Solution
  1. For each \(x \in [0, 3]\), the side of the square cross-section runs vertically from the \(x\)-axis (\(y = 0\)) to the line \(y = 3 - x\): $$s(x) = (3 - x) - 0 = 3 - x$$ The cross-sectional area of the square slice is: $$A(x) = [s(x)]^2 = (3 - x)^2 = 9 - 6x + x^2$$
  2. Integrating \(A(x)\) from \(x = 0\) to \(x = 3\): $$\begin{aligned} V &= \int_0^3 A(x)\,dx = \int_0^3 (3 - x)^2\,dx \\ &= \left[ -\frac{(3 - x)^3}{3} \right]_0^3 \\ &= 0 - \left( -\frac{3^3}{3} \right) = \frac{27}{3} = 9 \end{aligned}$$

Problem 2

[12 points]

Let \(\mathcal{R}\) be the region enclosed by the curve \(y = 2\sqrt{x}\), the horizontal line \(y = 0\), and the vertical line \(x = 1\).

  1. Set up but do not evaluate an integral for the volume of the solid obtained by revolving \(\mathcal{R}\) about the \(x\)-axis (Disk Method).
  2. Set up but do not evaluate an integral for the volume of the solid obtained by revolving \(\mathcal{R}\) about the \(y\)-axis using the Method of Cylindrical Shells.
View Solution
  1. Disk Method (Revolved about the \(x\)-axis):
    Slicing perpendicular to the \(x\)-axis, the radius of each circular disk is \(R(x) = 2\sqrt{x}\).
    The cross-sectional area is: $$A(x) = \pi [R(x)]^2 = \pi (2\sqrt{x})^2 = 4\pi x$$ Integrating from \(x = 0\) to \(x = 1\): $$V = \int_0^1 4\pi x\,dx = 4\pi \left[ \frac{x^2}{2} \right]_0^1 = 4\pi \left(\frac{1}{2}\right) = 2\pi$$
  2. Shell Method (Revolved about the \(y\)-axis):
    For a vertical strip at position \(x \in [0, 1]\) rotated around the \(y\)-axis:
    • \(\text{Radius} = x\)
    • \(\text{Height} = 2\sqrt{x} - 0 = 2x^{1/2}\)
    • \(\text{Thickness} = dx\)
    Setting up the shell integral: $$\begin{aligned} V &= 2\pi \int_0^1 (\text{radius})(\text{height})\,dx = 2\pi \int_0^1 x \left(2x^{1/2}\right) dx \\ &= 4\pi \int_0^1 x^{3/2}\,dx \\ &= 4\pi \left[ \frac{2}{5}x^{5/2} \right]_0^1 = 4\pi \left(\frac{2}{5}\right) = \frac{8\pi}{5} \end{aligned}$$

Quiz 4: Average Value of a Function, MVT for Integrals, and Work

Date: 09/15/2026

Problem 1

[8 points]

Consider the function \(f(x) = x^2 + 1\) on the interval \([0, 3]\).

  1. Find the average value \(f_{\text{avg}}\) of \(f(x)\) on \([0, 3]\).
  2. Find the number \(c \in [0, 3]\) guaranteed by the Mean Value Theorem for Integrals such that \(f(c) = f_{\text{avg}}\).
View Solution
  1. By definition, the average value of a continuous function on \([a, b]\) is: $$f_{\text{avg}} = \frac{1}{b - a} \int_a^b f(x)\,dx = \frac{1}{3 - 0} \int_0^3 (x^2 + 1)\,dx$$ Evaluating the definite integral: $$\int_0^3 (x^2 + 1)\,dx = \left[ \frac{x^3}{3} + x \right]_0^3 = \left( \frac{27}{3} + 3 \right) - 0 = 9 + 3 = 12$$ Therefore: $$f_{\text{avg}} = \frac{1}{3}(12) = 4$$
  2. Set \(f(c) = f_{\text{avg}} = 4\): $$c^2 + 1 = 4 \implies c^2 = 3 \implies c = \pm\sqrt{3}$$ Since we require \(c \in [0, 3]\), choose the positive value: $$c = \sqrt{3} \approx 1.732$$

Problem 2

[12 points]

An inverted conical water tank (vertex pointing downward) has a height of \(8\text{ m}\) and a top circular radius of \(2\text{ m}\). The tank is filled with water to a depth of \(5\text{ m}\).

Set up but do not evaluate a definite integral representing the total work required to pump all of the water out over the top rim of the tank. (Use water density \(\rho = 1000\text{ kg/m}^3\) and \(g = 9.8\text{ m/s}^2\)).

View Solution

Step 1: Coordinate Setup.
Place the origin \(y = 0\) at the bottom vertex of the cone and the top rim at \(y = 8\). The water occupies the interval \(y \in [0, 5]\).

Step 2: Geometry and Weight of a Typical Slice.
At height \(y\), let \(r(y)\) be the radius of a circular horizontal slab of thickness \(dy\). By similar triangles: $$\frac{r(y)}{y} = \frac{2}{8} = \frac{1}{4} \implies r(y) = \frac{1}{4}y$$ The volume and weight (force) of the slice are: $$\begin{aligned} dV &= \pi [r(y)]^2\,dy = \pi \left( \frac{y}{4} \right)^2 dy = \frac{\pi}{16}y^2\,dy, \\ dF &= \rho g\,dV = (1000)(9.8)\pi \left( \frac{y}{4} \right)^2 dy = 9800\pi \left( \frac{y}{4} \right)^2 dy\text{ N} \end{aligned}$$

Step 3: Distance and Integral Setup.
Each slice at height \(y\) must be lifted to the top rim at \(y = 8\), giving a displacement of \(8 - y\).
Integrating over the water depth \(y \in [0, 5]\): $$W = \int_0^5 9800\pi \left( \frac{y}{4} \right)^2 (8 - y)\,dy \quad \left( \text{or } \int_0^5 \frac{1225\pi}{2} y^2 (8 - y)\,dy \right)$$
